# UX, материалы уроков и восстановление позиции

Проверено 13 ноября 2026 года на отдельной локальной PostgreSQL 16. Рабочие записи и медиа не использовались для тестов.

## Автоматическая регрессия

`scripts/qa-release.ts` выполняет 47 проверок через реальные HTTP-обработчики Next.js и PostgreSQL. Проверены права гостя, ученика, другого курса и администратора; отзыв доступа и сессии; понижение роли; межсайтовые запросы; загрузка, повтор без дубликатов, переименование, замена, сортировка, удаление; ограничения формата, сигнатуры, размера потока и числа файлов; очистка после неудачной транзакции; сохранность байтов и русского имени; позиция отдельно от процента просмотра; задержавшиеся записи; доступ к следующему уроку без обязательного просмотра.

Для повторения запустите отдельный PostgreSQL на 127.0.0.1:55432 (БД oqu, пользователь oqu, тестовый пароль local-qa-only) и приложение:

```sh
DATABASE_URL=postgres://oqu:local-qa-only@127.0.0.1:55432/oqu AUTH_SECRET=qa-local-secret-only APP_URL=http://localhost:3100 SMTP_HOST='' MAX_MATERIAL_MB=1 pnpm dev --port 3100
```

В другом терминале:

```sh
OQU_RELEASE_QA=local pnpm exec tsx scripts/qa-release.ts
```

Скрипт привязан к локальным адресам, требует явного флага, создаёт QA-данные и оставляет их для браузера. Следующий запуск заменяет свои курсы и аккаунты. Cookie и идентификаторы сохраняются только в игнорируемый output/qa-fixture.json. Никогда не запускайте тестовый сервер с рабочей базой.

## Браузер

Chromium / Playwright, ширины 360, 390, 768, 1280, 1536 px:

- Лендинг, кабинет, урок и редактор урока: проверены расположение элементов и отсутствие горизонтального переполнения.
- Скачан файл с русским именем; проверено соответствие байтов через API.
- Перемотка с клавиатуры, пауза и обновление страницы: восстановлена сохранённая секунда. Исправлен пропуск loadedmetadata до гидратации при загрузке из кеша.
- Мобильное меню удерживает фокус; Escape возвращает его на кнопку открытия.
- Искусственный сетевой сбой загрузки: показана ошибка, повтор завершён успешно. Несохранённый текст урока пережил загрузку файла.
- Сохранение урока показывает результат; удаление урока удаляет запись вложения и файл с диска.
- Вход: показ пароля, ошибка, сохранение введённого email, успешная авторизация.
- Заявки: фильтр и вторая страница из 31 тестового обращения.

Снимки находятся в локальном output/playwright и не входят в Docker-образ или Git. Эмуляция размеров не заменяет проверку Safari и физического iPhone.

## Выкладка

- Миграция 0010 только добавляет таблицу и поля; существующие пользователи, уроки, видео, доступы и оплаты сохраняются.
- Материалы используют существующий постоянный volume /app/storage. Полный backup.sh архивирует их вместе с видео; db-only — только метаданные.
- scripts/update.sh делает резервную копию БД до обновления и оставляет старое приложение работающим во время сборки.
- www перенаправляется на домен из APP_URL. Origin проверяется на всех изменяющих API-запросах.
- Перед выкладкой обязательны pnpm typecheck, pnpm lint, pnpm build и проверка /api/health после неё.
